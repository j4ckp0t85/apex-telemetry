# 🛡️ Privacy Policy

**Last Updated:** October 7, 2026
**Project:** APEX TELEMETRY (Desktop Companion Application)

APEX TELEMETRY is built with a fundamental commitment to user privacy, local data sovereignty, and security. We believe that your riding, device, and telemetry data belongs strictly and exclusively to you.

---

## 1. Local Processing & No Developer Analytics

* **No Remote Telemetry or Tracking by the Developers**: APEX TELEMETRY does not send session statistics, CSV files, GPS sample arrays, device identifiers or usage analytics to the developers.
* **Offline Analysis, Online Map Background**: CSV parsing, charts, route construction and sample inspection run on your computer. The map is available only in Single session view and requests OpenStreetMap tiles when the background is enabled and that session has valid GPS data. Aggregate views clear the map and stop tile loading. These requests disclose the viewed area and network information described below. The app does not send telemetry beacons or background diagnostic reports.
* **No Third-Party Trackers or Analytics**: The application contains **zero** third-party analytics libraries, advertising frameworks, crash reporting tracking SDKs, or profiling tools.

---

## 2. Local-Only Storage & File Processing

All files inspected or generated by APEX TELEMETRY remain strictly on your local computer storage:

* **Telemetry CSV Logs & GPS Geometry**: Telemetry files are loaded and parsed locally in memory to render charts and route geometry. CSV contents and exact sample arrays are not uploaded. Map tile requests can nevertheless reveal the approximate geographic area being viewed.
* **Non-Destructive Read-Only USB Sync**: When syncing CSV logs from an Android device connected via USB (Windows Portable Devices API), the synchronization engine operates strictly in a **read-only** mode on the mobile device. Files are copied exclusively to your chosen local directory; files on the phone are never deleted, altered, or overwritten.
* **Application Settings**: User preferences (such as selected storage directories, theme choice, and window dimensions) are stored locally in the standard application data folder (`userData/settings.json`).
* **Map Cache & Background Switch**: Chromium may cache map tile images locally according to the provider's HTTP cache headers. The online-background switch is kept for the current app window and defaults to enabled on a new launch. No tile requests are made when the selection has no usable coordinates. Disabling the switch stops new tile loading but does not erase already cached tiles or retract requests already sent.
* **Data Ownership & Deletion**: You retain complete ownership over all your files and telemetry logs. You can move, archive, inspect, or delete them directly via your operating system's file manager at any time.

---

## 3. External Links & Network Boundaries

* **OpenStreetMap Tiles**: With **Online background** enabled, the app loads the currently viewed tiles from `https://tile.openstreetmap.org`. The provider receives your IP address, an application-specific User-Agent and tile coordinates/zoom levels, which reveal the approximate viewed area. No account or API key is used. Requests follow normal HTTP caching; the app does not bulk-download tiles or prefetch offline map regions. Provider processing is governed by the [OpenStreetMap Foundation privacy policy](https://osmfoundation.org/wiki/Privacy_Policy).
* **Local Map Library**: Leaflet JavaScript and styles are bundled locally. No remote map scripts, geocoding service or road-routing service receives GPS samples. The route remains usable if online tiles fail or are disabled.
* **Voluntary Support & Repository Links**: The application contains user-initiated external links (e.g., donating via Ko-fi / PayPal, or visiting the GitHub repository). Clicking these buttons opens the link in your system's default web browser (`shell.openExternal`). APEX TELEMETRY does not monitor, log, or track these browser navigations.
* **Attribution Links**: Leaflet and OpenStreetMap attribution links also open in the system browser when clicked.

## 4. Regulatory Compliance

### General Data Protection Regulation (GDPR - EU 2016/679)
The developers do not receive imported CSV files or GPS sample arrays. Online map requests involve a third-party provider and can reveal location-related information; they are outside any claim that all processing is offline. Disable the map background to use the local route viewer without new tile requests.

### California Consumer Privacy Act (CCPA / CPRA)
The developers do not operate an analytics collection or sale service in the application. The network behavior of the map provider is described above and in its own privacy policy.
